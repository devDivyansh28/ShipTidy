Slide 6 · Architecture Impact

System Strengths, Security & Future Scope

Engineering decisions that guarantee scalability, data isolation, and low-latency reviews.

Key Technical Innovations

Durable Step Execution with Inngest

Decouples serverless timeouts from heavy AI prompt inference. Retries automatically on rate limits or transient GitHub API spikes without losing review state.

Contextual Vector Search (Pinecone RAG)

Rather than reviewing diffs in isolation, ShipTidy indexes repository syntax trees and injects relevant surrounding project conventions into the LLM context.

Enterprise Security & Resilience

Cryptographic Webhook Verification

All incoming GitHub webhooks are verified against SHA-256 HMAC signatures using the GitHub App Secret. Tampered payloads are rejected at the edge.

Multi-Tenant Installation Isolation

Prisma models enforce strictly scoped queries based on installationId. Users can only observe and manage repositories they own or administer.

Ready for Production Deployment

Scalable on Vercel Edge, Neon/Supabase Postgres, and Inngest Serverless Cloud.
